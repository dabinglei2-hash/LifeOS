# LifeOS

本地优先的个人生活管理 PWA：学习、日程、收支、统计、妙想、健康、笔记、习惯及目标。当前不具备真实多用户认证或产品 AI。

启动：`python -B server/static_server.py --help`（参数以实际帮助为准）；构建：`node scripts/build-pwa.mjs dist`，输出路径必须尚不存在。检查：`node scripts/check-pwa.mjs dist`。

研发系统：[LifeOS-DevTeam](https://github.com/dabinglei2-hash/LifeOS-DevTeam)。[迁移报告](docs/DUAL_REPOSITORY_MIGRATION_REPORT.md)。
