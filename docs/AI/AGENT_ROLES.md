## 角色注册

六个稳定产品身份：main、user_information、conversation_archive、knowledge_writer、external_research、proactive。注册表还包含协议版本、能力、工具白名单、允许任务类型、数据类别、超时/重试策略、是否启用、责任人及配置版本。未知/停用身份不得调度；模型不能自注册或自修改权限。注册表未来由受控部署配置实现，本次不创建运行配置。

| 角色 | 职责与输入 | 输出给Main | 权限及禁止事项 |
| --- | --- | --- | --- |
| Main Agent | 唯一日常对话入口；识别意图/需求、是否调用工具/专业Agent、拆解任务、分派与汇总、核对冲突及结果 | 统一最终答复或待确认方案；专业角色结果均先审核 | 调度/审核；不能代用户授权、绕开服务端检查、直接改数据库 |
| User Information Agent | 读取获准个人资料、有效长期记忆、目标、学习/工作/生活与偏好；按任务检索最少背景 | 来源、as_of、有效期、缺失/冲突及上下文摘要 | 严格只读；不得创建事实、修改/删除原资料；不能访问其他账号 |
| Conversation Archive Agent | 接收统一网关的原始用户/Main消息及重要Agent任务/结果，保存原文、索引、生成摘要，提取目标/计划/偏好/决定 | 可追溯历史检索、摘要版本、候选长期记忆 | 原文追加；摘要不可覆盖原文；候选不是个人事实；确认记忆由受控服务按授权版本保存 |
| Knowledge Writer Agent | Main任务与已授权资料；编写项目/个人文档、学习/工作计划、日周月总结、研究整理/知识库与分析 | 有来源的草稿、差异、拟保存目标、版本条件 | 草稿允许；Main审核且有效用户授权后经数据接口保存正式版本；不删原资料、不覆盖重要文档 |

## 工作边界

资料编写与聊天归档都可产出摘要，但对象不同：Archive管忠实对话摘要；Writer管面向任务的总结/文档。两者引用同一源，不各自建私有事实库。Archive只产候选长期记忆，不能将推断升级为确认事实；User Information负责检索，不负责整理或回写。

External Research可建议学习资料，但只有Writer按Main分派形成计划草稿，正式日程仍通过既有create_schedule_draft和独立用户确认业务接口；本任务不扩大三个首期工具的能力。

所有专业Agent必须返回[通信信封](AGENT_COMMUNICATION.md)，证据不足明确标记；不能主动调用其他Agent。Main解决冲突：当前业务服务事实优先，随后用户已确认信息；保留分歧和时间，必要时询问用户。专业Agent输出只是建议，不是执行凭据。

产品工作不依赖Codex在线。Scanner只采开发证据，Reviewer只审方案/Diff，Builder唯一写开发工作区；它们不进入产品注册表，也无用户记忆或生产库权限。跨系统协作只允许获准的脱敏需求/缺陷报告，不透传密钥、生产写权限或私人对话。
